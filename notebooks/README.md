# Notebook de la entrega final

El notebook final documentado se colocará aquí cuando estén cerrados los modelos,
la interpretación y las revisiones del equipo. No se creó ni modificó un notebook
durante la reorganización.

Para reutilizar el código, ubicar la raíz del repositorio, añadirla a `sys.path`,
establecerla como directorio de trabajo con `os.chdir(raiz)` e importar `proyecto`
antes de importar los módulos. Ejecutar los comandos de
reproducción con el lanzador; no copiar implementaciones paralelas al notebook.
