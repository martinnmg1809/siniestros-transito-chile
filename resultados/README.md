# Resultados y evidencia

Proyecto: **Predicción dinámica de siniestros en carreteras chilenas**.

| Carpeta | Uso |
|---|---|
| modelos | Comparación vigente de Entrega III: tablas, figuras y auditorías; 14.420 siniestros |
| modelos/artefactos | Modelos joblib locales, excluidos de Git |
| eda | Diagnóstico exploratorio previo; sus cifras corresponden a esa etapa |
| flujo | Auditoría de fuentes y cobertura candidata; no acredita exposición vehicular |
| cierre | Comprobaciones, cobertura por contrato y matriz de compromisos del equipo |
| conaset | Inventario y consultas de fuentes oficiales para estudiar actualización; no son datos incorporados a los modelos |
| validacion | Evaluación corregida anterior a la nueva comparación; universo histórico distinto |
| prototipo | JSON y salidas locales del prototipo anterior; excluidos de Git |

No combinar métricas de poblaciones diferentes. Las auditorías existentes conservan
los nombres de archivos y hashes de sus corridas originales. La reorganización está
trazada en `config/migracion_estructura.csv` y `docs/estructura.md`.
